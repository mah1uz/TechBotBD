# 🤖 TechBot BD

Bengali gadget recommendation chatbot for Bangladesh. RAG-based, supports
General Mode (free, multi-shop) and Shop Mode (B2B, single-shop inventory).
Switchable LLM backend (Groq cloud / Ollama local).

---

## Quickstart

```bash
pip install -r requirements.txt
cp .env.example .env             # add your GROQ_API_KEY
python scripts/clean_data.py     # generates techbot/data/products.csv
streamlit run app.py
```

First Streamlit launch downloads the embedding model (~120MB). Subsequent
launches start in ~5 seconds.

### CLI mode

```bash
python main.py                    # Groq (default)
python main.py --backend ollama   # Local Ollama
python main.py --lang en          # English
```

---

## LLM backends

**Groq (recommended for demo).** Set `GROQ_API_KEY` in `.env`. Uses
`llama-3.3-70b-versatile`. Free tier on console.groq.com is enough for testing.

**Ollama (local).** Install from https://ollama.com, pull the model
(`ollama pull gemma3:4b`), make sure `ollama serve` is running, then
toggle "Local" in the sidebar.

## Architecture

For a walkthrough of every NLP component (preprocessing, intent routing,
embeddings, FAISS retrieval, prompt engineering, etc.), see
`docs/ARCHITECTURE.md`.

Project layout:

```
techbot/
├── config.py          # paths, model names, thresholds
├── preprocessor.py    # Bengali/Banglish text normalization
├── prompts.py         # system prompts + prompt builder
├── router.py          # intent classification (comparison/filter/recommendation)
├── rag_pipeline.py    # FAISS index + retrieval
├── tools.py           # price/category extraction, comparison, link block
├── llm.py             # Groq + Ollama backends
├── google_search.py   # CSE fallback when retrieval is empty
├── pipeline.py        # orchestrator — the only file that imports everything
└── data/
    └── products.csv   # generated by scripts/clean_data.py

scripts/clean_data.py  # raw → master CSV (run once)
data/raw/              # source scrapes
docs/ARCHITECTURE.md   # NLP component reference
app.py                 # Streamlit UI
main.py                # CLI mode
```

## Modes

**General Mode** — uses the full master CSV (Ryans laptops + Dazzle phones,
413 products).

**Shop Mode** — a retailer uploads their inventory CSV. Required columns:
`name`, `category`, `price_bdt`. Optional columns get sensible defaults.
Download the template from the sidebar.

---

## Adding a new shop later

1. Add `data/raw/<shop>_<category>.csv` with the master schema
2. Add a `process_*` call in `scripts/clean_data.py` before the concat
3. Re-run `python scripts/clean_data.py`
4. Restart the app

The cleaning script's `search_url()` already has a Startech entry as a hook.
